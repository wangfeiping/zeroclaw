  在哪里申请 key 和充值
 
  都在 Comfy 的平台站点:

  - 申请 API key:https://platform.comfy.org/profile/api-keys ,登录后创建,key 以 comfyui- 开头。只在创建时显示一次,记得当场保存。
  - 充值:同一站点的账户页面里购买额度(credits),额度与账户绑定,API key 调用时从中扣除。

  这个地址来自 comfy-mcp 和 comfy-cli 的官方文档;我没有登录过该平台,所以最低充值金额、支付方式(是否支持国内的卡)和新账户有无赠送额度都无法确认,需要你登录后查看。
  
  拿到 key 后写进 /opt/ai/comfy/.env 并重建容器(步骤见前面的回复)。之后可以让 agent 调 list_partner_models 和 partner_model_schema 查看可用模型,这两个工具本身不花钱。

  控制花费的两点

  - 第一次测试建议用 P-Image 最低质量或 Recraft Flash 出图,用 Grok Video Lite 480p 或 Veo 3 Lite 720p 出视频,单次都在 20 美分以内。
  - 视频节点的时长、分辨率、是否带音频都会成倍影响价格。让 agent 自己选参数时,最好在提示里限定模型和分辨率,否则它可能选到 1 美元以上的档位。

  5 秒视频快的半分钟到一分钟,多数在 2 到 5 分钟。 分辨率越高、时长越长越慢,高峰期排队还会更久。

  对你架构的影响

  视频生成是分钟级的,这会直接影响 agent 的调用方式:

  - 不要让 agent 同步等待。 comfy-mcp 推荐的用法是 run_workflow(wait=False) 提交后拿到任务 ID,再用 job(action="wait") 或 job(action="status") 轮询,完成后 fetch_outputs 取结果。同步等一个 5
    分钟的视频,很可能撞上 ZeroClaw 的工具调用超时。
  - ZeroClaw 的 MCP 工具超时可能需要调大。 它的 MCP 服务配置里有一个 tool_timeout_secs 字段,默认值我没有查。跑视频前建议确认一下,必要时在 [[mcp.servers]] 里显式设置。
  - 节点自身的上限很宽。 内置节点每 5 秒轮询一次,最多 480 次,也就是最长等 40 分钟才放弃,所以瓶颈不会在 ComfyUI 这一层。
 
  另外,容器这边除了网络请求几乎不耗时:CPU 模式下 ComfyUI 只负责提交任务、轮询和下载结果,不参与计算,所以总耗时基本等于厂商的生成时间加上下载视频的时间。

  等你配好 key,我可以用最便宜的档位各跑一次图片和视频,给你这台机器上的实测时间。
